01 · Data Acquisition

Downloads the full Hacker News dataset from Google BigQuery and saves it as local Parquet files for fast querying in subsequent notebooks.

Prerequisites: 1. Create a GCP project at console.cloud.google.com and enable the BigQuery API 2. Run gcloud auth application-default login in your terminal 3. Copy .env.example to .env and set GCP_PROJECT_ID

BigQuery free tier: 1 TB/month of queries. This notebook uses ~10 GB.

# Stories per year
per_year = con.execute("""
    SELECT
        YEAR(posted_at) AS year,
        COUNT(*) AS n_stories,
        AVG(score) AS avg_score
    FROM stories
    GROUP BY 1
    ORDER BY 1
""").df()
